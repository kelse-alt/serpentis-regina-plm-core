# Saved tech-pack directory — v0.9.0

Open the private cloud workroom from the existing GitHub workroom's **Open private
cloud workroom** link. Sign in with the same ChatGPT account on your phone and
computer. The cloud workroom lives at:

https://serpentis-regina-techpack-studio.amaya-hunt-2047.chatgpt.site/workroom/

Choose **Directory** to find an older pack by title, style number or description.
Open it, edit it, and save. Wait for **Saved to cloud** before switching
devices. **Refresh directory** retrieves the latest online list. Named revisions
preserve earlier versions and their images; restoring keeps a backup revision.
Revisions are working history, not garment approval.

The private cloud edition uses a hosted database. The original GitHub PWA and
downloaded standalone file still use their existing device storage. To transfer
an older device-only pack, download its pack JSON there and import it into the
private cloud edition. Nothing automatically uploads the old browser database.
The existing POM library remains available from the private workroom.

Online saves require a connection. If saving fails, your on-screen edits remain
available and JSON export provides a backup. An older device is prevented from
overwriting a newer saved pack: export its edits, reopen the latest online copy,
and reconcile the changes. A directory refresh does not replace the open draft.

The private workbook starter preserves the supplied workbook's four garment
components and 60 POM definitions. Measurement values, targets and tolerance
limits remain blank, and the garment unit requires an explicit choice. Body-form
references remain separate. The original source workbook stays unchanged.

Only generic application code is published in the public repository. The
workbook starter, source cells and artwork are retained in the separate private
Site source and database. Authenticated records are scoped to the signed-in user;
existing POM library records and routes are preserved.
