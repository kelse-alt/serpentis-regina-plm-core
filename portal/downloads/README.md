# Open the interactive portal

1. Sign in to GitHub with an account that has access to this private repository.
2. Open [Portal-Entrance-Preview.html](Portal-Entrance-Preview.html).
3. Click **Download raw file** (the downward-arrow icon near the top-right of the file view).
4. Open the downloaded HTML in Chrome or Edge. Allow the three embedded sculptures a moment to load.

Drag a head to turn it or choose **Enter the World**. No Node.js installation, build step or separate model download is required. The atelier link needs an internet connection; the entrance's code, styles and models are embedded.

This is a downloadable preview, not a hosted website. The current Squarespace site is unchanged. Amaya and KLS currently open introduction panels.

GitHub accepted the source branch and draft release, but its separate release-asset upload service returned an authentication error. This identified HTML snapshot is therefore versioned here as a delivery fallback. Rebuild it with `npm run standalone` from the parent `portal/` directory and deliberately update this snapshot for a new reviewed milestone. It contains no client data or technical portfolio documents.
